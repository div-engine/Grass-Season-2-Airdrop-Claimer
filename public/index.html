Main → Secondary distribute
Each secondary wallet receives a random amount between min and max. Min = max sends a fixed amount.
Secondary → Main collect
Sweeps the whole balance of every secondary wallet back to the main wallet, leaving each empty (minus the tiny fee it pays). Requires each secondary's private key.
Reclaim rent token only
Do this step in order: run this after Collecting the token, but before Collecting SOL. Each wallet must still have a little SOL to pay the close fee — so always collect SOL last.
Closes each secondary's empty token account and returns its ~0.00204 SOL rent to the main wallet. Select a token above, Collect it first (accounts must be empty), and each secondary needs a little SOL for the close fee.
⚠️ Order matters for token round-trips — reclaim rent BEFORE collecting SOL:
  1. Collect the token (e.g. USDC) — empties each secondary's token account
  2. Reclaim rent — closes the now-empty accounts, ~0.00204 SOL each back to main (each wallet still needs a little SOL to pay the close fee)
  3. Collect SOL — sweep the leftover SOL back last
If you collect SOL first, wallets are emptied and can't pay the close fee, so the rent stays stuck. A token account must also be empty before it can be closed.
