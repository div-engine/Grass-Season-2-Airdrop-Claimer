### Частые проблемы[cite: 1]

#### Приложение не запускается[cite: 1]
- **Решение:** Нажмите правой кнопкой мыши на `GrassSol.exe` → "Запуск от имени администратора"[cite: 1].
- Проверьте настройки брандмауэра Windows[cite: 1].
- Если Windows SmartScreen блокирует запуск: нажмите "Подробнее" → "Выполнить в любом случае"[cite: 1].

#### Ошибки RPC (429 Rate Limit)[cite: 1]
- **Решение:** Добавьте приватные (премиум) RPC-узлы в `config.json`[cite: 1].
- Уменьшите количество параллельных потоков в настройках клейма[cite: 1].
- Подождите и повторите попытку в непиковое время[cite: 1].

#### Ошибка подключения через прокси[cite: 1]
- **Решение:** Проверьте формат прокси: `протокол://ip:port` или `протокол://user:pass@ip:port`[cite: 1].
- Поддерживаются: `http://`, `https://`, `socks4://`, `socks5://`[cite: 1].
- Проверьте прокси по отдельности перед добавлением в список[cite: 1].

#### "Insufficient SOL for Transaction" (Недостаточно SOL для транзакции)[cite: 1]
- Минимально необходимо: ~0.008 SOL на один кошелек[cite: 1].
